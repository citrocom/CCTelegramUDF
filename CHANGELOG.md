# Changelog

## 1.0.0 (2026-11-22)

First release.

- `CCTelegramUDF.au3`: request engine (UTF-8 JSON, multipart uploads, local COM error handler, timeouts, proxy,
  automatic retry on HTTP 429), own JSON parser/encoder, long polling, keyboards, file download, escaping helpers,
  detailed error information
- `CCTelegramUDF_Methods.au3`: all 194 methods of Telegram Bot API 10.5 (November 22, 2026), generated by
  `tools/gen_methods.py`
- `compat/Telegram.au3`: compatibility layer for release v0.1 of xLinkOut/telegram-udf-autoit
- `compat/Telegram2024.au3`: compatibility layer for the 2024 rewrite of xLinkOut/telegram-udf-autoit
- Example bot, offline and online tests
